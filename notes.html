Week 1: Java Basics & Syntax

Topic: Introduction to Java execution, variables, and output.

Key Concepts

  • public class: The primary structure containing your code.
  • main method: The entry point where the program starts running.
  • System.out.println(): Prints text to the console.

Code Example

public class NotesExample {
    public static void main(String[] args) {
        // Output text to the console
        System.out.println("Notes for Week 1");
    }
}
