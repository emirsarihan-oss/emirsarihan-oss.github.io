1.5 Casting and Ranges of Values

  • Type Casting: Explicitly converting a value from one primitive data type to another.
    • Example: (double) 2 casts the integer 2 into a double value (2.0).
  • Integer Boundaries: Integers in Java are 32-bit signed values ranging from Integer.MIN_VALUE ($-2^{31}$) to Integer.MAX_VALUE ($2^{31} - 1$).
  • Integer Overflow/Underflow: Attempting to store a calculation that exceeds these limits wraps around to the opposite side of the limit, causing erroneous values.
