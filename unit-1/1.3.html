1.3 Expressions and Output

  • Console Output: System.out.println(value); prints data to the console and moves the cursor to a new line.
  • Escape Sequences:
    • \" prints a literal quotation mark within a String without closing the string early.
    • \n inserts a newline character.
  • Mixed-Type Operations: Any arithmetic expression evaluating at least one double operand converts the result to a double.
  • Integer Truncation: Division involving two int values drops the fractional component completely without rounding (e.g., 9 / 10 evaluates to 0).
  • Modulus Operator (%): Returns the remainder of division. Evaluating a smaller number modulo a larger number yields the smaller number (e.g., 3 % 5 evaluates to 3).
