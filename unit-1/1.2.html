1.2 Variables and Data Types

  • Data Type Categories:
    • Primitive Data Types: Hold raw values directly in memory (e.g., int for integers, double for decimals, boolean for true/false).
    • Reference Data Types: Store memory addresses that reference complex objects (e.g., String).
  • Naming & Conventions: Reference types begin with an uppercase letter, while primitive types are lowercase. Variable names cannot begin with numbers or special characters (other than $ or _).
  • Declaration vs Initialization:
    • Declaration: Specifying the data type and variable name (e.g., int score;).
    • Initialization: Assigning an initial value to the variable (e.g., score = 100;).
  • String Concatenation: Combining text fragments or values using the + operator (e.g., "Score: " + score).
