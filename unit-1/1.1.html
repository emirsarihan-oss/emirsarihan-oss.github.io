1.1 Introduction to Algorithms, Programming, and Compilers

  • Sequencing: Executing code statements in a specific step-by-step order from top to bottom.
  • Object-Oriented Language: Java organizes programs into reusable objects and classes rather than just isolated functions.
  • Main Method Entry Point: When executing a Java class, the Java Virtual Machine (JVM) always begins execution inside the public static void main(String[] args) method.
public class MyClass {
    public static void main(String[] args) {
        // Code execution starts here
    }
}
  • Case Sensitivity & Naming: Java keywords (e.g., public, class, void) are strictly lowercase. Built-in class names (e.g., String, System) begin with an uppercase letter.
  • Syntax Rules: Code statements end with a semicolon (;). Closing curly braces (}) do not require semicolons.
  • Types of Program Errors:
    • Syntax Errors: Compile-time errors caused by incorrect language structure/grammar (e.g., missing semicolons). Reported directly by the compiler.
    • Runtime Errors: Bugs that occur while the program is actively executing (e.g., dividing by zero or unexpected inputs).
    • Logic Errors: Bugs where the program runs without crashing but produces incorrect results due to flawed algorithm design.
