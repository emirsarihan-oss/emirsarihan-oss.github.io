1.6 Compound Assignment Operators

Compound operators provide shorthand notation for performing arithmetic operations on a variable and reassigning the updated result back to that variable.

Operator + - * / %
Written Out x = x + 1 x = x - 1 x = x * 2 x = x / 2 x = x % 2
Compound x += 1 x -= 1 x *= 2 x /= 2 x %= 2
Extra Concise x++ x-- — — —
