1.9 Method Signatures

  • Procedural Abstraction: Using a method based on what it does without needing to understand its internal code implementation.
  • Method Calling: Invoking a method by referencing its name followed by parentheses containing necessary arguments.
  • Method Headers & Signatures:
    • Header: Defines method accessibility, return type, name, and parameter list.
    • Return Type: The data type returned back after execution (e.g., void returns no value).
    • Parameters vs. Arguments: Parameters are placeholder variables in the method header. Arguments are the literal values passed during a call.
  • Method Overloading: Defining multiple methods within the same class using identical names but differing parameter lists (different types, order, or quantity).
