1.4 Assignment and Input

  • Null References: Object reference variables (like String) can be assigned null, indicating they currently point to no object in memory.
  • Reading User Input: The Scanner class from java.util reads keyboard input from standard input (System.in).
import java.util.Scanner;

Scanner scan = new Scanner(System.in);
String name = scan.nextLine(); // Reads full line of text input
