1.7 APIs and Libraries

  • Software Libraries: Collections of pre-written code created by other developers to perform common tasks without rewriting fundamental code.
  • Application Programming Interface (API): Documentation outlining available classes, methods, parameters, and behaviors within a library.
  • Classes, Attributes, and Behaviors:
    • Attributes: Data associated with an object, stored inside instance variables.
    • Behaviors: Operational actions an instance can execute, defined by methods.
  • Packages: Groups of related classes. Imported into code files using statements like import java.util.*;.
